# こどもマネー・ラボ V2

V1からデータ移行しない新規版です。

## 機能
- おとなモード / こどもモード
- 低学年向けのひらがな・やさしい言葉
- 子ども複数登録
- 入金・出金・使い道
- 貯金 / 全世界株式 / S&P500
- 投資元本・評価額・損益
- ACWI / S&P500指数を使った簡易インデックス連動
- 将来シミュレーション
- 暴落体験
- 目標管理
- 金融教育コンテンツ
- JSONバックアップ・復元
- GitHub Pages / iPhone対応

## GitHub Pages
ファイルをリポジトリのルートへアップロードし、Settings → Pages → Deploy from a branch → main / root を選択してください。

## インデックス連動
投資評価額は「投資元本 × 現在指数 ÷ 基準指数」の簡易計算です。配当・為替・税金・信託報酬・トラッキングエラー等は完全には反映しません。公開APIのCORSやレート制限で取得できない場合があります。

## データ
ブラウザのLocalStorageに保存します。V1からの自動移行はありません。設定からJSONバックアップできます。

金融教育用であり、投資成果を保証するものではありません。
